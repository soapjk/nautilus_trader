# Implementation Plan: LongPort Adapter API Support

**Branch**: `001-longport-adapter` | **Date**: 2026-01-03 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/001-longport-adapter/spec.md`

**Note**: This plan follows OKX adapter architecture while adapting to LongPort OpenSDK's unique characteristics (Rust-based SDK with Python bindings, QuoteContext/TradeContext abstractions).

## Summary

Implement production-ready LongPort adapter for NautilusTrader by wrapping LongPort's official OpenSDK. Follow OKX/BitMEX architectural patterns (two-layer HTTP/WebSocket clients, dual-tier architecture) but adapt for LongPort's SDK uniqueness: SDK is Rust-based with Python bindings (vs pure REST/WebSocket), uses app_key/app_secret/access_token auth (vs custom signing), provides QuoteContext/TradeContext abstractions (vs raw HTTP/WebSocket). Support Hong Kong, US, and A-share markets with market data and order execution capabilities.

## Technical Context

**Language/Version**: Rust 1.92+ (core), Python 3.12+ (API layer)
**Primary Dependencies**:
- LongPort OpenSDK (`longport` Python package, `longport-openapi` Rust crate)
- NautilusTrader core (nautilus_core, nautilus_model, nautilus_execution)
- PyO3 for Python-Rust FFI, Tokio async runtime, Serde JSON serialization

**Storage**: In-memory caching with optional Redis backing via Nautilus cache layer
**Testing**: Rust cargo test with mock Axum servers, Python pytest in .venv, `sh ./scripts/run_debug.sh` for validation
**Target Platform**: Linux x86_64/ARM64, macOS ARM64 (matching NautilusTrader support)
**Project Type**: Adapter integration (hybrid Rust core + Python API layer)
**Performance Goals**: Sub-100ms P99 order execution, 100+ orders/sec, 1000+ quote ticks/sec, <30s to load 2000+ instruments
**Constraints**: Must use LongPort OpenSDK (no direct HTTP/WebSocket), explicit config params (no env vars), zero data loss, type-safe PyO3 boundaries
**Scale/Scope**: Support 2000+ HK stocks, 5000+ US stocks, 5000+ A-shares, 10+ concurrent subscriptions, 100+ simultaneous orders
